# Phase 2: AWS Cloud Security & DevSecOps

## Overview

This repository documents my **Phase 2 cloud security projects**, focused on building, securing, monitoring, and automating infrastructure in **Amazon Web Services (AWS)**.

Throughout Phase 2, I used **Terraform Infrastructure as Code (IaC)** and AWS security services to apply concepts including **least privilege, Zero Trust, network monitoring, identity management, and DevSecOps**.

## Phase 2 Capstone: Secure AWS Architecture

As part of a **four-person group project**, we designed and deployed a secure AWS environment using **Terraform** and integrated automated security scanning through a **GitHub Actions CI/CD pipeline**.

The project included:

- Custom AWS VPC architecture
- Public and private networking components
- EC2 web server deployment
- Security Group controls
- Terraform Infrastructure as Code
- Automated `tfsec` security scanning
- GitHub Actions CI/CD pipeline
- Secure AWS deployment and testing
- Infrastructure teardown to prevent unnecessary cloud costs

### Business Impact

The project demonstrated how **Infrastructure as Code and automated security testing** can reduce manual configuration errors and identify cloud vulnerabilities before infrastructure reaches production.

**Skills:** AWS • Terraform • GitHub Actions • tfsec • DevSecOps • VPC • EC2 • Cloud Security
